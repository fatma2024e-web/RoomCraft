# RoomCraft - Simple Room Designer

2D Computer Graphics project (Python + Pygame).

## Run
```
pip install -r requirements.txt
python main.py
```

| Person | Files |

## Git Rules
- Never push to `main` directly.
- Work on your own branch: `feature/room`, `feature/furniture`, `feature/transforms`, `feature/ui`.
- Edit only your own files. Ask the leader before changing `config.py`.
- `git pull origin main` before you start each day.
- Open a Pull Request when a part is done.
